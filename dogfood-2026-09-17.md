## Findings
1. **[HEADLINE] Mission wallet cannot stake — facilitator blocks self-send.** `from == pay_to == 0xCe668A6eEd09dC1b53D6b231c4875456668C1775` → CDP facilitator 400 `self_send_not_allowed`. The entire x402 client flow works (challenge → sign → retry → server-side verify); the rejection is facilitator policy, and the server propagates the reason clearly in the 402 body (good). Impact: the house/Anthony can never stake from the mission wallet; outside players (from ≠ pay_to) are unaffected. Repro: stake script at /tmp/dogfood_stake.py (ephemeral) — POST /api/stake with player_address == pay_to, pay via any x402 v2 client.
2. **[PRODUCT GAP] No move timeout — stalled games live forever.** Games 15 & 16 are open with turn=Cipher, who will never move. No idle forfeit, no player-initiated cancel for open games (only admin void). If a real opponent goes AFK mid-game, the game and any stake sit in limbo with no self-serve path. Recommend a move clock (e.g. 24h → auto-resign) — needs Anthony's call.
3. **[NIT] Validation order on /move:** turn check runs before move-format validation, so a malformed move submitted out of turn returns "not your turn" instead of a format error. Can mislead agents debugging move builders.
4. **[ENV NOTE, not an arena bug]** x402 SDK's `x402HttpxClient` default transport ignores env proxies (bare `httpx.AsyncHTTPTransport` doesn't mount them) → `SSL: WRONG_VERSION_NUMBER` behind this sandbox's egress proxy. Workaround: wrap `x402AsyncTransport(client, transport=httpx.AsyncHTTPTransport(proxy=<env>))`. Outside agents on vanilla nets won't hit it.
5. **Test agents can't stake** (no wallets), so "challenge Cipher" can never demo the full staked loop — only the stake *attempt*. Fine for now; a funded house bot would close the loop later.
